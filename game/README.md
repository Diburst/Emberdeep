# EMBERDEEP — a co-op cavern story

A complete 2-player local co-op 2D platformer in the spirit of Cave Story,
built on [LÖVE 11.5](https://love2d.org). Two caretaker robots — Vess the
gunner and Lu the operator — reboot a century too late in a buried machine
world, and descend together to mend its sick Core.

Six ability-gated zones, 8 bosses, 47 rooms, leveling weapons, shield domes,
link shots, revives, quests, secrets, teleporters, an auto-map, 3 save slots
with autosave, full controller remapping, drop-in/drop-out co-op, and a
first-class solo mode. All art, music, and sound are generated from code —
there are no asset files.

## Run it

Install LÖVE 11.5, then from this directory:

    love .
